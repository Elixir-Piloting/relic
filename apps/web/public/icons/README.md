# Database Provider Icons

Place the following PNG icon files in this directory:

- `postgresql.png` - PostgreSQL logo (20x20px recommended)
- `mysql.png` - MySQL logo (20x20px recommended)
- `mongodb.png` - MongoDB logo (20x20px recommended)
- `sqlite.png` - SQLite logo (20x20px recommended)
- `turso.png` - Turso/LibSQL logo (20x20px recommended)
- `supabase.png` - Supabase logo (20x20px recommended)
- `planetscale.png` - PlanetScale logo (20x20px recommended)

You can download official logos from:
- PostgreSQL: https://www.postgresql.org/media/
- MySQL: https://www.mysql.com/about/legal/logos.html
- MongoDB: https://www.mongodb.com/brand-resources
- SQLite: https://www.sqlite.org/logo.html
- Turso: https://turso.tech/brand
- Supabase: https://supabase.com/brand-assets
- PlanetScale: https://planetscale.com/brand

If icons are not found, the component will fallback to emoji icons.
